# CMS Law Frontend

Enterprise Content Management System (CMS) frontend built with **React 19**, **Vite**, **TypeScript**, **TanStack Router**, **TanStack Form**, and **Tailwind CSS v4**.

---

## Tech Stack

- **Package Manager:** `pnpm`
- **Framework:** React 19 + Vite + TypeScript (Strict Mode)
- **Routing:** TanStack Router (`@tanstack/react-router`) with file-based routing & auto code-splitting
- **Forms & Validation:** TanStack Form (`@tanstack/react-form`) + Zod
- **Styling & Icons:** Tailwind CSS v4 + `clsx` & `tailwind-merge` (`cn` utility) + `lucide-react`
- **Code Quality:** ESLint (Flat Config, `strictTypeChecked`), Prettier, TypeScript
- **Git Workflow:** Husky, `lint-staged`, Commitlint, Commitizen, `validate-branch-name`

---

## Prerequisites

- **Node.js:** `v20+` (recommended `v22+`)
- **pnpm:** `v10+`

---

## Getting Started

### 1. Install Dependencies

```bash
pnpm install
```

> Running `pnpm install` automatically initializes Husky git hooks via the `prepare` script.

### 2. Start the Development Server

```bash
pnpm run dev
```

### 3. Build for Production

```bash
pnpm run build
```

### 4. Preview Production Build

```bash
pnpm run preview
```

## Git Workflow & Standards

### Commit Message Convention

Commits are validated by **Commitlint** using [Conventional Commits](https://www.conventionalcommits.org/):

```text
<type>(<optional scope>): <subject>
```

- **Allowed types:** `feat`, `fix`, `docs`, `style`, `chore`, `refactor`, `test`, `revert`
- **Rules:**
  - `type` and `subject` must be **lower-case**
  - `subject` must **not** end with a period (`.`)
  - Header max length is **100 characters**
- **Examples:**
  - `feat(auth): add login form validation`
  - `fix: guard optional chaining before .split()`
  - `docs(readme): document project setup and folder structure`

### Branch Naming Convention

Branch names are validated on `git push` against:

```text
<feature|bug|release|setup|hotfix|refactor>/<ticket-id>-<short_description>
```

- Protected branches: `main`, `develop`, `staging`
- `short_description` uses lower-case words separated by underscores (`_`)
- **Examples:**
  - `feature/123-add_login_page`
  - `bug/456-fix_broken_link`
  - `setup/101-init_cms_repo`

### Active Git Hooks (`.husky/`)

| Hook         | Action                                             | Purpose                                                    |
| :----------- | :------------------------------------------------- | :--------------------------------------------------------- |
| `pre-commit` | `pnpm exec lint-staged`                            | Runs `eslint --fix` and `prettier --write` on staged files |
| `commit-msg` | `pnpm exec commitlint --edit "$1"`                 | Enforces Conventional Commits format                       |
| `pre-push`   | `pnpm exec validate-branch-name && pnpm run build` | Enforces branch naming and verifies the production build   |
